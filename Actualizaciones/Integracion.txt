La forma correcta de conectar una app Android escrita en Kotlin con una base de datos en Supabase sigue estos pasos fundamentales:

1. **Crear un proyecto en Supabase**  
   - Regístrate en supabase.com y crea un nuevo proyecto.  
   - Accede al Dashboard para crear tablas y agregar datos (puedes usar el editor SQL para definir tablas y políticas de acceso).  
   - Obtén la URL del proyecto y la clave pública anónima (anon key) desde la configuración del proyecto, que necesitarás para la conexión desde la app[1][2].

2. **Configurar tu proyecto Android en Android Studio**  
   - Crea un nuevo proyecto Android con Kotlin.  
   - Agrega permiso para acceso a internet en el archivo `AndroidManifest.xml`:
     ```xml
     
     ```
  
3. **Agregar las dependencias necesarias en `build.gradle` (app)**  
   - Incluye las librerías de Supabase para Kotlin y el cliente Ktor para llamadas HTTP:
     ```kotlin
     plugins {
       id("org.jetbrains.kotlin.plugin.serialization") version "$kotlin_version"
     }
     
     dependencies {
       implementation(platform("io.github.jan-tennert.supabase:bom:$supabase_version"))
       implementation("io.github.jan-tennert.supabase:postgrest-kt")
       implementation("io.github.jan-tennert.supabase:auth-kt")
       implementation("io.ktor:ktor-client-android:$ktor_version")
     }
     ```
   - Reemplaza las variables `$kotlin_version`, `$supabase_version`, y `$ktor_version` con las versiones actuales recomendadas[1][7].

4. **Inicializar el cliente Supabase en Kotlin**  
   - En tu `MainActivity` o espacio global, crea el cliente así:
     ```kotlin
     val supabase = createSupabaseClient(
       supabaseUrl = "https://tu-proyecto.supabase.co",
       supabaseKey = "tu_anon_key"
     ) {
       install(Postgrest)
       install(Auth) {
         flowType = FlowType.PKCE
         scheme = "app"
         host = "supabase.com"
       }
       install(Storage)
     }
     ```
   - Esto habilita acceso a la base de datos PostgREST, autenticación y almacenamiento desde la app[1][7].

5. **Realizar consultas a la base de datos**  
   - Usa las interfaces provistas para consultar tablas, insertar o actualizar datos. Ejemplo para leer datos de una tabla:
     ```kotlin
     val response = supabase.postgrest.from("instruments").select().execute()
     if (response.error == null) {
         val instruments = response.data
         // Trabaja con los datos retornados
     }
     ```
   - Puedes también usar la autenticación integrada para usuarios y manejar sesiones[1][7].

6. **Opcional: Uso de inyección de dependencias (Hilt)**  
   - Para proyectos más complejos, puedes proveer la instancia del cliente Supabase mediante un módulo Hilt para facilitar pruebas y modularidad[7].

## 2. Diseño y Comportamiento en la App

### • Diseño de cada Promoción

**Recomendación visual:**
- **Imagen** a la izquierda (o arriba en móvil).
- **Título** en negrita, grande.
- **Descripción** corta debajo del título.
- **Botón** con el texto de acción (por ejemplo, "Activar").
- **Color** de fondo personalizado si lo deseas (usa el campo `color`).

**Ejemplo visual:**

```
+------------------------------------------------------+
| [Imagen]  Título de la Promoción (negrita)           |
|           Descripción corta                          |
|           [ Botón de acción ]                        |
+------------------------------------------------------+
```

### • Interacción del Usuario

- **Al tocar el botón de la promoción:**
  - Si el campo `action_url` tiene un enlace, abre ese enlace en el navegador.
  - Si no tiene enlace, puedes mostrar un mensaje de éxito o más detalles.

- **Al tocar la card completa (opcional):**
  - Puedes abrir una pantalla con más detalles de la promoción, o simplemente no hacer nada.
